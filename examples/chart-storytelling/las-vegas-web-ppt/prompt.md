# 测试 Prompt

围绕 Las Vegas Grand Prix 制作一套至少 8 个章节的视觉叙事型网页幻灯片，判断这场城市级体育娱乐事件究竟是真正的商业爆款，还是噱头很足但转化不均的昂贵秀场。

面向体育商业观察者、城市事件和现场娱乐从业者，专业、清晰、有判断力地讲清：

- 收入和声量峰值是否同步出现；
- premium ticket / hospitality 是否主导票务收入；
- 酒店 ADR uplift 和本地商户承接是否错位；
- 入口动线和 peak delay 是否构成现场体验瓶颈；
- sponsor media value 和 merch stockout 是否暴露供给问题；
- 高、低 ROAS 渠道是否呈现明显效率差异。

视觉方向采用霓虹、城市赛道和拉斯维加斯夜间娱乐感，首屏可使用 generated image 作为 hero background image。关键图表应主动加入克制的区域标注、点标注、差异标注或透明度高亮；百分比显示 % 后缀；高亮只用于建立视觉主次，不得改变数据编码。
