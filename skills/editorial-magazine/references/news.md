# 新闻资讯：报头 → 主新闻 → 次新闻网格

使用 `assets/news.html`。保留报刊气质，满足三层结构：

- 顶部：本次主题标题／刊头；细条放真实日期、栏目或期数（没有期数就省略）。
- 中部：一张大图、一条主新闻的标题与短摘要。标题可置于底部渐变遮罩上；照片太花时放图下，确保可读。摘要说明“发生了什么”，不要用一句口号代替新闻。
- 下部：其他新闻用 CSS Grid，每条子新闻默认包含小标题、正文和至少一张相关配图；文字与自己的图片放在同一 `section`。末尾来源细线收束。

模板提供一条主新闻＋四条次新闻的密集示例，正文合计约830字（含标点），不是每页必须凑满的指标。主图横跨版心，图下导语可分两栏；次新闻两列两行，正文可沿小图绕排，保留事实、背景和出处。每格都有独立视觉锚点，避免连续四块纯文字；用户明确要求纯文字时才省略配图。

正文从20px左右起调；主新闻大图与主标题的视觉等级仍高于次新闻。先用完整材料安排各新闻占位，减少不必要的模块内边距和装饰，再按实际行数协调图高与字号。不要继续使用每条35–70字的短摘要预算，也不因条数增加就直接分页。只给一条时保留主新闻和相关背景，不伪造其他新闻；完整稿件确实放不下时再续页。

## 子新闻配图与绕排

原文没有图片、只有头像或界面图标时，先主动联网搜图，不能直接省略主图和子新闻配图。“尽量使用原文／不要改写”不等于用户要求纯文字。没有现场照片时检索相关主体、场所或物件的资料图并标注；借此版式排故事选读时使用标注清楚的情境配图，不冒充当事人或现场。禁止伪造现场不等于禁止相关网图。只有用户明确要求纯文字或限制外部素材时按其限制处理；搜图无果再按[缺图兜底](imagery.md#原文无图与原文保留要求)处理并记录实际尝试。

每条分别准备与事件、主体或主题直接相关的图片，必读[正式配图与联网检索](imagery.md)。缺少用户图片时主动联网检索新闻原文照片或官方活动素材；没有现场照片时搜索有来源的主体／场所资料图，图注明确“资料图”。不能因缺照片就手写 SVG 主题示意图或几何图标。确有数据／机制需要解释时可另配事实支持的信息图，但不把它当作省略搜图的理由；生图仅用于明确标注的概念插画，不伪造新闻现场。

图片与简短图注放在该条的 `figure.news-photo` 中。1080px页面可从约170–190px宽、110–140px高起排，左右浮动或图文并列均可，正文沿图流动并在下方接续。海报、图表按内容用contain，避免裁掉年份、图例或主体；图注说明图像类型与来源，完整链接放sources.md。模板的矢量图仅演示图文关系，正式交付全部替换。

增加图片时先压缩装饰留白、协调主图高度和各条篇幅，保留背景与关键事实；不要靠缩小正文、裁切或把新闻变成一句话来塞图。检查每条确有配图、图文对应、照片裁切、图注与正文／来源／页脚间距。

## 按内容随机配色

先按主新闻语义确定候选色系，再随机选一个主题色。品牌色或用户明确色值优先。科技／产业可选深蓝、靛蓝、深青；自然／环境可选森林绿、苔绿、深青；文化可选酒红、紫、赭色；生活可选陶土、橄榄、深玫红；综合资讯使用克制深色。

```bash
python scripts/choose_theme.py --family technology
# 需要复现时使用输出中的 seed
python scripts/choose_theme.py --family technology --seed 123
```

将输出 `accent`、`paper`、`ink`、`onAccent` 写入 HTML 的 CSS 变量，并把 seed 与选择理由记在 `sources.md`。该脚本仅提供色值，不渲染页面、不建立页面 schema。每次新作品随机一次；同组所有页复用该主题。不要让不同新闻各自随机造成彩虹网格。脚本检查纯色上的文字对比度；照片叠字仍需在原图上人工核验遮罩强度。
