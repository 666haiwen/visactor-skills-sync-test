# 人物生平：核心肖像与人生全景

使用 `assets/biography.html` 作为主图，配合 `assets/biography-details.html` 中的三张详情页组成一组。适合生平回顾、历史人物、艺术家与科学家专题、职业轨迹、纪念文章；在世人物使用“截至某年／目前”，不暗示已经去世。

## 与人物介绍的分流

本场景以出生背景、人生阶段、转折、代表成果和影响的时间跨度为中心。单纯出现“经历”二字不强制套用生平版，依据材料与用户指定版式处理。未指定人物且只要求增加模板时，用明确虚构的样稿验证，不擅自替用户选一个真实人物撰传。

若材料围绕一段事件或项目逐节点展开，而非介绍整个人生与成果，使用[时序故事](story-sequence.md)。例如“某人的生平”用本场景，“完成第一部作品的经历”用时序故事；用户指定版式优先。

## 版式关系

- 顶部：小栏目名＋醒目的姓名／年代＋一段人物导语。姓名比修饰语大，生卒年或出生年按证据写；无可靠引语时不编名言。
- 左上辅图：在姓名与导语左侧放一张全身照、早年照或身份相关小图，与中央主肖像形成大小对比；辅图不能只是主肖像的重复缩略图。
- 右下辅图：在作品栏右端安排工作现场、代表活动或有依据的合影，配简短图注；让图片对应相邻叙事，不把婚恋关系当固定栏目。
- 中央：大幅肖像约占页宽40%–55%，头肩形成焦点，人物轮廓向下延展。优先有来源的真实照片或历史肖像；需要去背景时按[透明素材与宿主路由](cutouts.md)执行，豆包办公直接使用 MediaKit，保留身份。缺图先标“肖像待补”，不能把示例脸换上真实姓名。
- 左侧：3–5个有日期或阶段的关键经历，按时间先后串联，每段说明发生了什么及为何重要。可在上方加简短身份资料，但不把身高、体重、婚恋等参考图栏目视为必填字段。
- 右侧：3–4个专题模块，例如作品、研究、创作方法、合作与影响。使用细长强调色标题条和连续短文，不改成统一大圆角卡片。
- 底部：代表作、关键成果、重要关系或档案图片横条，按材料择一；没有合适配图时用简洁的作品／成果文字目录。配图与标签一一对应，正文不可压在肖像脸部或复杂衣纹上。

模板固定保留左上与右下两个辅图位置，连同中央大肖像形成三图层级。正式制作优先使用同一人物有来源的不同照片，核对人物、关系、时间与图注；缺少辅图时明确标注待补，不编造历史照片。仅在虚构模板示例或用户授权的说明性插图中使用AI生成场景并标注，不能冒充真实人生事件。辅图可用透明抠图或保留原照片边界，按素材选择；调整页首与底栏空间，不删正文给图片腾位置。

模板使用中央定位的透明肖像＋左右两个独立正文流。每侧开头的浮动占位用 `shape-outside` 定义对应半边的排除区域，文字沿轮廓排布；段落继续使用正常文流，不逐行定位。不要用参考截图作整页背景再盖字，也不复制其出版物标识。

### 双侧轮廓绕排

`shape-outside` 作用于 float，不能直接加在 Grid/Flex 子项或绝对定位肖像上。当前模板让 `.chronology` 与 `.topics` 各占正文宽度一半，内部的 `.portrait-exclusion` 分别向右／向左浮动，肖像在它们中央显示。

更换透明肖像或改变尺寸后，先生成与显示几何一致的形状：

```bash
python scripts/portrait_wrap.py --image /路径/portrait.png \
  --width 972 --image-height 840 --flow-height 940 --gap 22
```

脚本只读 alpha，不编辑图片；输出 `leftShape`、`rightShape` 写入 `--left-shape`、`--right-shape`。当前 1080px 画布、左右54px页边距，对应972px正文；图片在整块972×840区域内 **contain、center、不裁切**，浮动高度和正文区均为940px。缩放画布时要同步这些尺寸并重新生成，不能修改图片位置／object-view-box后仍沿用旧轮廓。输出的 `minimumTextWidth` 太小时应缩小肖像或扩大版面，避免只剩三四字一行。

轮廓按行高附近的小段计算保守边界，`gap` 已包含水平和垂直安全留白，因此模板中 `shape-margin:0`；不要重复加大间距。发丝和肢体内的小空隙不填文字，以免产生碎行。两侧 section 不设 overflow/flow-root 或额外浮动，否则可能阻断跨段落绕排。标题条的底色放在内联 span 上，不能让整块背景和横线跨过肖像；长标题允许自然换行。

左侧年代、右侧专题分别顺序阅读，不声称一段文章自动穿过中央图片流到另一侧。短尾行可调整断句或给末尾短语设置不换行，不能删正文或压缩字形。验收时逐行看头发、肩膀、手臂与脸部边缘：DOM边界检查无法发现透明图片内的文字碰撞。没有透明素材时退回独立矩形图片栏，不能套用示例轮廓冒充实际绕排。

## 资料与主图内容密度

先整理时间、事件、出处，再写阶段叙事；争议日期保留不确定性，未记载就省略，不以整齐的时间轴补造人生事件。个人经历、时代背景与后人评价应区分。直接引语核对原文出处；代表作的名字、年份和人物归属需核实。真实资料可来自用户文章，缺少资料时按宿主检索能力查来源，模板示例不能充当事实来源。

维持参考的杂志密度：先保留充分的阶段叙事，再分配给两侧连续正文与底部作品栏。每个人生阶段用材料说明背景、行动、转折及后续影响；专题段落承载具体方法、例子或评价依据，作品栏说明内容与意义，不能只列书名年份或一句标签。按材料自然分段，不强制每栏等长，也不重复改写同一事实凑篇幅。

1080px宽的密集生平版可用18–20px正文、约1.35–1.5行高，阶段标题20–22px。字重默认轻正文300、姓名及栏目/作品标题400；用字号、颜色和间距建立层级，避免大面积粗体，实际字体缺少轻字重时使用可用的常规字重。减少超大的姓名区和重复的双层小标题、收紧栏目间距，再按肖像轮廓分配正文空间；肖像仍保留主要视觉地位。材料充分时不默认压成每栏一句的简报，材料不足时不为凑字编造。容量以实际排版为准，示例字数不是生成配额；不得裁切、缩放整页或用省略号隐藏溢出内容。

## 四张人物专题的分工

默认一组四张：保留现有全景主图，再用 `assets/biography-details.html` 的三种子版式展开具体人物；用户只要一张、指定其他页数或材料不足时按实际需求调整，不为凑四页编造内容。三张详情是主动的专题展开，不是把主图溢出的文字平均切页。

| 页 | 阅读任务 | 构图与内容 |
| --- | --- | --- |
| 01 人物全景 | 先知道这个人是谁 | 沿用中央肖像、两侧绕排、左上与右下辅图；概览身份、阶段与成果 |
| 02 人生相册 | 理解他/她如何走到今天 | 一张阶段主照片＋两三张不同阶段的辅助照片；年份、阶段名和短图注紧贴对应图片 |
| 03 作品图集 | 具体看做了什么、怎样做到 | 一件代表作大图＋两三张相关作品、手稿或局部图；配作品名、年份、一个看点，可搭配工作现场 |
| 04 人物与世界 | 看清关系、影响与日常 | 一张活动/合影主图＋三张不同侧面的照片，图文交错；图注说明人、事和关系，最后用一句有出处的话或编辑概括收束 |

页02–04的标题和栏目随人物材料调整：科学家可讨论研究与成果，创业者可讨论产品与决策；不能把示例的编辑职业、书目或工作步骤当作通用必填内容。跨页可重复必要的姓名、年份或作品名，但详情要增加事件、证据、过程与解释，避免整段重复主图。评价归属和事实/推断要清楚，不凭姿态推断性格，不伪造引语或成就。

主图是 `biography.html`，详情文件只含后三张，避免重复维护主图。制作时复制主图文档，追加详情样式与三个 `<article data-page>`；详情样式以 `.bio-detail` 为作用域，不覆盖主图。整组仅保留一套实际配色变量：默认白底、轻正文300/标题400、统一强调色和页码，随机一次后共用。可复用同一人的素材，用全身、活动、局部肖像形成不同阅读重点，不必每页生成新的照片；透明PNG或原图裁切不得改变真实事件含义。

### 详情页采用多图叙事

主图维持密集全景；页02–04以图片承担信息，不沿用主图的长文密度。以每页3–5个有区别的视觉素材、约150–300字正文和图注作为试排起点，通常让图片占内容区约60%–75%；这不是内容配额，按材料、裁切和阅读效果调整。正文可从20–24px、1.45–1.5行高起排。用一两句解释具体照片，不把长文缩小塞回图片之间。

照片应覆盖不同阶段、事件、作品或关系；不要把同一张肖像重复裁切来凑数量。跨页复用与主题有关的素材可以，但同页应有主次与内容差异。真实人物的作品用原始作品图，不把生成的封面、场景当实物或历史照片；模板中的虚构书封是可编辑HTML示意，实际制作要替换。素材不足时减少图片、明确待补或按用户素材调整，不能编造人生事件。模板只提供矢量占位，其灰色不代表最终照片的风格。人物照片默认保留原色，优先使用有来源的真实彩色照片；原始黑白历史照片可原样使用，不必补色。已故人物也不自动转黑白，按素材、专题语境和用户要求决定；不得仅凭死亡状态机械选择。

### 整组风格锁定

先从主图确定一份共享样式，再编排详情：同一背景 `--paper`、强调色 `--accent`、正文色 `--ink`、反白色 `--on-accent` 和派生线色 `--rule`；同一正文字体栈、标题字体栈、300/400字重层级；同样的页边距、页眉细线、图注与页码规则。三张详情只改变构图和图文比例，不各自抽主题、换背景、另选字体或使用无关的装饰色。作品原图可保留自身色彩，页面文字与装饰继续使用共享主题。

默认白底，照片保持自然矩形、适度留白，以细线、字级和强调色连接主图；避免统一大圆角卡片把杂志改成仪表盘。需要合并模板时只保留一套实际主题变量；详情CSS限定在 `.bio-detail`，主图构图与密度不因新增详情而变化。逐页核查文字/图片/页脚间距与独立PNG导出，同时并排检查四页的计算样式、主图未被污染，以及375px宽预览下的图文主次。

## 主题与交付

主图与所有详情页默认纯白背景（--paper:#FFFFFF）＋一种强调色＋深色正文，HTML预览底色也使用同一白色。参考粉红只是强调色示例。新作品默认执行 `scripts/choose_theme.py --style editorial --family general` 随机选择协调主题（明确领域时可用对应family）；将强调色用于姓名、日期和标题条，背景默认固定白色，仅用户明确指定其他背景时覆盖。用户色系优先，整组随机一次，保存seed与实际色值。模板中的粉红只是示范，不代表默认锁定粉红；不得直接复制模板色值跳过选择。将输出的 accent / ink / onAccent 写入 --accent / --ink / --on-accent；--paper 使用 #FFFFFF，不采用候选主题中的有色纸底，theme.json 与来源记录保存实际白底值；--rule 自动从强调色派生，姓名、年代、标题条、作品分隔线和图注同步变化。同组续页、重新导出与普通修改复用选定主题，只有新作品或明确要求换色时重新抽取。肖像默认保留原色，不用灰度滤镜统一人物图片；只有用户要求或有明确编辑意图并说明处理时才采用黑白。背景、主题色、字体和图注承担风格统一，不把主题色染到皮肤上。

按共同导出规则交付自包含HTML、PNG和sources.md，记录人物资料、作品图片及肖像来源，生成或编辑图像明确标注。核对时间顺序、在世状态、肖像对应、边栏与脸部/轮廓、正文与底部横条的间距；原尺寸和约375px预览都要查看。模板使用虚构人物、作品封面和肖像／工作／活动图槽占位，正式制作必须替换全部示例，并按真实透明图片重算绕排轮廓。
