# 中心人物＋事件网格

适合逐项阅读人物经历、希望每个事件都有独立图文卡片的需求。`template: center-grid`，`layout` 可横可竖。标题占1/8，余下7/8为网格和简短来源。

- 三行网格的正中央是一格人物剪贴画，沿透明轮廓加白边；保持比例，不跨过事件文字。其余4–8张事件卡片围绕中央格排布：中行左右各一张，上、下行按事件数合并为1–3格，避免卡片过窄过高。横版1920×1280，竖版1080×1920。
- 每张卡片包含编号与日期、标题、图片、正文；事件卡片不设背景色，以留白区分。窄高卡片上下堆叠，宽卡片在标题下图文并列。按位置从上到下、同高从左到右排列事件，并标顺序号；网格位置不表示真实年距。
- 图片直接写在 `events[].image`，事件与图片不会分开排序。可用 `imageCaption` 说明实际拍摄年份、资料画面或相关物件，不使用与事件无关的头像来凑卡片。无法找到可信场景时可用相关节目单、作品或档案，并标明关联；没有素材就减少节点或改用照片墙模板。
- `portraitCutout` 沿用共用抠图协议。中央人物不重复占用某个事件编号；其身份或舞台角色在来源说明中写清。
- 正文建议30–45字，标题6–10字。容量由具体卡片宽高决定，优先缩写摘要或分章；不要塞满65字上限再缩字号。图像支持 `cropPosition` / `fit`，生成后检查动作与面孔是否完整。

与照片墙的区别：照片墙侧重连续影像与独立时间线；网格把每段文字和图片收进同一张事件卡片。不从参考图继承未经核实的文字、观点、图标或数据。
